# CONN-CRAFT-SUITE-API — Requirements

Governing specification: [spec.md](spec.md).

Each row identifies one connector behavior and its verification target.

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-CRAFT-SUITE-API-R001` | **Credential references.** The connector must resolve authorized credential references in `craft_suite_api/auth.py` when a client is requested. Caller chain: an MCP tool call reaches `get_client` in `craft_suite_api/auth.py`, which calls `_build_client` and then `_reference_auth` to turn the configured credential reference into SDK auth before the first request. Shape: `_build_client` registers the TLS profile and client cleanups on one `ExitStack`, and `close_client` closes that stack. | `tests/test_auth.py::test_client_resolves_reference_and_cleans_up` must observe reference resolution and resource cleanup. |
| `CONN-CRAFT-SUITE-API-R002` | **Bounded API requests.** The connector must enforce origin, TLS, timeout, and response-size limits in `craft_suite_api/openapi_client.py`. Caller chain: a write or read tool calls `OpenApiClient.execute` in `craft_suite_api/openapi_client.py`, which calls `_authorize` and then `_send`. Shape: `OpenApiClient` holds the `ClientPolicy` and `MAX_BYTES` bound and reads the body through `read_response` in `craft_suite_api/openapi_responses.py`. | `tests/test_api_wrapper.py::test_oversized_response_rejected`, `::test_redirect_not_followed`, `::test_response_deadline_enforced` and `::test_invalid_provider_origin_rejected` must exercise oversized responses, redirects, deadlines and rejected origins through the real client. |
| `CONN-CRAFT-SUITE-API-R003` | **MCP registration.** The connector must register its operation router through `craft_suite_api/mcp_server.py` and `craft_suite_api/mcp/__init__.py`. Caller chain: the `scion_sdk.connector` entry point calls `get_mcp_instance` in `craft_suite_api/mcp_server.py`, which calls the SDK `build_server`, which calls each `register_<domain>_tools` registrar in `craft_suite_api/mcp/__init__.py`. Shape: each registrar is a `functools.partial` of `register_domain` in `craft_suite_api/openapi_runtime.py` bound to `get_client`. | `tests/test_artcraft_mcp_validation.py::test_mcp_instance_registration` must construct the production server without vendor requests. |
| `CONN-CRAFT-SUITE-API-R004` | **Native content contracts.** The connector must publish packaged prompts, skills, ontology, and its manifest through `craft_suite_api/mcp_server.py`. Caller chain: the SDK `build_server` called from `get_mcp_instance` in `craft_suite_api/mcp_server.py` serves the packaged `skills/`, `ontology/` and `prompts/` directories with no content argument. Shape: the content is declared by the `scion_sdk.connector` and `scion_sdk.prompt_providers` entry points in `pyproject.toml`, and no connector code lists it. | `tests/test_default_content_surfaces.py::test_default_content_surfaces` and `tests/test_source_contract.py::test_served_prompts_match_admitted_capabilities` must list the packaged skills, ontology and prompts through the production server. |
| `CONN-CRAFT-SUITE-API-R005` | **Withhold unscoped ingestion.** The connector must not expose generic ingestion before a tenant/source-scoped ArtCraft mapping and complete receipt contract exist. Caller chain: no tool or entry point reaches an ingestion path, because `craft_suite_api.kg_ingest` and `craft_suite_api.api.api_client_base` are absent from the package. Shape: the test asserts both module specs are missing with `importlib.util.find_spec`. | `tests/test_source_contract.py::test_unscoped_ingestion_is_unavailable` must reject import of the removed ingestion starter. |
| `CONN-CRAFT-SUITE-API-R006` | **Destructive-write confirmation.** Each write tool in `craft_suite_api/openapi_runtime.py` must accept an optional `confirm` argument that is never sent upstream, and a write that is not confirmed must return the SDK refusal as a clean result instead of an error. Caller chain: an MCP client calls a write tool, `OpenApiTool.run` in `craft_suite_api/openapi_runtime.py` calls `confirm_write` in `craft_suite_api/openapi_execution.py`, which calls the SDK `ctx_confirm_destructive` before any outbound request. Shape: `OpenApiTool.run` pops `confirm`, `confirm_write` passes it as `explicit_confirm` and returns `scion_sdk.mcp.context.confirmation_refusal` when unconfirmed, and `write_outputs` widens the write tools' output schema to admit that refusal. | `tests/test_destructive_confirmation_transports.py::test_stdio_no_auth_destructive_call`, `::test_http_no_auth_localhost_destructive_call` and `::test_http_jwt_destructive_call` must show that a client without elicitation is refused with no upstream write until `confirm=true`, and that an eliciting client is asked and then writes. |
